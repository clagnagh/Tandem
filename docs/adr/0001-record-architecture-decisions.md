# 1. Record architecture decisions

Date: 2026-10-02. Status: Accepted.

## Context

Tandem is a learning project. Months from now, "why is it built this way?"
should have a written answer, and Claude Code should be able to read it.

## Decision

Write an ADR for every significant decision, in `docs/adr/NNNN-title.md`,
using the sections Context, Options, Decision and Consequences. Claude
drafts; the human owner edits and accepts.

## Consequences

Decisions are cheap to revisit because their reasons are on record. Each
phase's retrospective links to the ADRs written during it.
